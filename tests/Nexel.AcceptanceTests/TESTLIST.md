# Семантика — итерация 4, этап 1

- [ ] Неизвестные имена, обращения вне области видимости и повторные объявления.
- [ ] Затенение, инициализация и присваивание переменных.
- [ ] Корректная точка входа, разрешение вызовов, арность и типы аргументов.
- [ ] Типы операндов, выражений и возвращаемых значений.
- [ ] Обязательный возврат из функции с результатом.
- [ ] Ошибки в невызываемых функциях обнаруживаются до выполнения программы.
- [ ] Синтаксические ошибки и ошибки выполнения сохраняют свой тип.
