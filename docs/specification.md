# Спецификация языка Nexel

## 1. Введение

Nexel — учебный строго типизированный императивный язык программирования. Программа располагается в одном исходном файле, точкой входа является функция `main`.

Базовые типы языка:

- `int` — целые числа;
- `string` — строки;
- `bool` — логические значения;
- `void` — отсутствие возвращаемого значения.

Язык предусматривает переменные с явным типом, выражения, ветвления, циклы, функции, массивы и структуры. Синтаксис близок к языкам семейства C: блоки ограничиваются фигурными скобками, инструкции завершаются точкой с запятой.

В этой версии спецификации описана лексическая структура языка.

## 2. Лексика

Nexel чувствителен к регистру. При разборе используется правило максимального совпадения: если из текущей позиции можно распознать несколько лексем, выбирается самая длинная.

### 2.1. Пробельные символы

Вне строковых литералов игнорируются:

| Символ | Обозначение |
| --- | --- |
| пробел | ` ` |
| горизонтальная табуляция | `\t` |
| перевод строки | `\n` |
| возврат каретки | `\r` |

### 2.2. Комментарии

Поддерживаются два вида комментариев:

- `//` — до конца строки или файла;
- `/* ... */` — до ближайшей последовательности `*/`.

Вложенные многострочные комментарии не поддерживаются. Незакрытый многострочный комментарий является лексической ошибкой.

### 2.3. Идентификаторы

Идентификатор состоит из латинских букв, цифр и символа `_`. Первый символ должен быть латинской буквой или `_`.

```text
identifier ::= (letter | "_") (letter | digit | "_")*
letter     ::= "a".."z" | "A".."Z"
digit      ::= "0".."9"
```

Регистр имеет значение: `value` и `Value` — разные идентификаторы. Кириллица в идентификаторах не допускается.

### 2.4. Ключевые слова

Зарезервированные слова:

```text
int string bool void
if else while return struct
true false
```

Ключевые слова чувствительны к регистру. Имена `main` и встроенных функций ввода-вывода ключевыми словами не являются.

### 2.5. Целочисленные литералы

Целочисленный литерал — непустая последовательность десятичных цифр:

```text
integer_literal ::= digit+
```

Знак `-` не входит в литерал и распознаётся как отдельный оператор. В этой версии не поддерживаются шестнадцатеричная, двоичная, восьмеричная, вещественная и экспоненциальная формы записи.

### 2.6. Строковые литералы

Строковый литерал заключается в двойные кавычки:

```text
string_literal ::= '"' (string_char | escape)* '"'
```

Поддерживаемые escape-последовательности:

| Последовательность | Назначение |
| --- | --- |
| `\"` | двойная кавычка |
| `\\` | обратная косая черта |
| `\n` | перевод строки |
| `\r` | возврат каретки |
| `\t` | горизонтальная табуляция |

Неэкранированные `\n` и `\r` внутри строки не допускаются. Незакрытая строка и неизвестная escape-последовательность являются лексическими ошибками.

### 2.7. Логические литералы

Логические литералы `true` и `false` являются ключевыми словами.

### 2.8. Операторы

| Категория | Операторы |
| --- | --- |
| арифметические | `+` `-` `*` `/` `%` |
| присваивание | `=` |
| сравнение | `==` `!=` `<` `<=` `>` `>=` |
| логические | `&&` `||` `!` |

Одиночные `&` и `|` недопустимы. Для составных операторов применяется правило максимального совпадения, поэтому `>=`, `==`, `!=`, `&&` и `||` распознаются как единые токены.

### 2.9. Разделители

| Лексема | Назначение |
| --- | --- |
| `(` `)` | группировка, параметры и аргументы функций |
| `{` `}` | границы блока |
| `[` `]` | работа с массивами |
| `;` | завершение инструкции |
| `,` | разделение элементов |
| `.` | доступ к полям структуры |

### 2.10. Лексические ошибки

Лексическая ошибка возникает в следующих случаях:

- встретился символ, не относящийся ни к одной допустимой лексеме;
- строковый литерал не закрыт;
- в строке использована неизвестная escape-последовательность;
- многострочный комментарий не закрыт;
- встретился одиночный `&` или `|`.

Ошибка содержит позицию в исходном тексте.
