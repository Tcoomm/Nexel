# Спецификация языка Nexel

## 1. Введение

Nexel — строго типизированный императивный язык программирования, разрабатываемый в рамках учебного проекта по созданию компилятора в промежуточное представление и собственной виртуальной машины.

Синтаксис языка основан на общих принципах C, C# и Java. Nexel намеренно содержит небольшой набор конструкций, чтобы реализация языка оставалась достижимой в рамках учебного проекта.

Весь исходный код программы располагается в одном файле. Точкой входа является функция `main`. Имя `main` не является ключевым словом и с точки зрения лексического анализа является обычным идентификатором.

Nexel является строго типизированным языком. Базовыми типами являются:

- `int` — целочисленный тип;
- `string` — строковый тип;
- `bool` — логический тип;
- `void` — отсутствие возвращаемого значения.

Язык предусматривает поддержку явно объявляемых переменных, арифметических и логических операций, операций сравнения, ветвлений, циклов, функций, массивов и структур. Для ввода и вывода предполагается использование встроенных функций.

В первой версии спецификации определяется только лексическая структура языка. Синтаксис и семантика конструкций будут описаны в следующих версиях.

## 2. Лексика

Исходный текст программы состоит из последовательности лексем. Лексический анализатор читает текст слева направо и преобразует его в последовательность токенов.

К лексемам Nexel относятся:

- идентификаторы;
- ключевые слова;
- целочисленные литералы;
- строковые литералы;
- логические литералы;
- операторы;
- разделители.

Пробельные символы и комментарии не образуют отдельных лексем и игнорируются лексическим анализатором.

### 2.1. Регистр

Nexel чувствителен к регистру.

Следующие идентификаторы являются различными:

```text
value
Value
VALUE
```

Ключевые слова также чувствительны к регистру. Например, `while` является ключевым словом, а `While` может использоваться как идентификатор.

### 2.2. Пробельные символы

К пробельным символам относятся:

- пробел;
- горизонтальная табуляция `\t`;
- перевод строки `\n`;
- возврат каретки `\r`.

Пробельные символы игнорируются лексическим анализатором и могут использоваться для разделения соседних лексем.

Например, следующие фрагменты эквивалентны с точки зрения лексического анализа:

```nexel
int value = 10;
```

```nexel
int
value
=
10
;
```

Пробельные символы внутри строковых литералов являются частью строки и не игнорируются.

### 2.3. Комментарии

Nexel поддерживает однострочные и многострочные комментарии.

Однострочный комментарий начинается с последовательности `//` и продолжается до конца строки:

```nexel
// Однострочный комментарий

int value = 10; // Комментарий после инструкции
```

Многострочный комментарий начинается с последовательности `/*` и заканчивается последовательностью `*/`:

```nexel
/*
    Многострочный
    комментарий
*/
```

Многострочные комментарии могут занимать одну или несколько строк.

Вложенные многострочные комментарии не поддерживаются. Первое встретившееся `*/` завершает комментарий.

Незавершённый многострочный комментарий является лексической ошибкой.

### 2.4. Идентификаторы

Идентификаторы используются для имён переменных, функций, параметров, структур и полей структур.

Первым символом идентификатора может быть:

- латинская буква `A-Z` или `a-z`;
- символ `_`.

Остальные символы могут быть:

- латинскими буквами `A-Z` или `a-z`;
- цифрами `0-9`;
- символом `_`.

Правило идентификатора:

```text
(letter | "_") (letter | digit | "_")*
```

Примеры корректных идентификаторов:

```text
x
value
Value
user_name
_value
value2
some_long_name
```

Примеры некорректных идентификаторов:

```text
2value
user-name
```

Если последовательность полностью совпадает с ключевым словом, она распознаётся как ключевое слово, а не как идентификатор.

Кириллические символы в идентификаторах не поддерживаются.

### 2.5. Ключевые слова

В Nexel используются следующие ключевые слова:

```text
int
string
bool
void
if
else
while
return
struct
true
false
```

Ключевые слова нельзя использовать в качестве пользовательских идентификаторов.

Имена `main`, `print` и функций ввода не являются ключевыми словами. Их специальное назначение определяется на следующих этапах обработки программы.

### 2.6. Целочисленные литералы

Nexel поддерживает десятичные целочисленные литералы.

Целочисленный литерал состоит из одной или нескольких цифр:

```text
digit+
```

где `digit` — символ от `0` до `9`.

Примеры:

```text
0
1
42
100
100500
```

В текущей версии языка не поддерживаются:

- шестнадцатеричные числа;
- двоичные числа;
- восьмеричные числа;
- вещественные числа;
- экспоненциальная форма записи.

Знак `-` не является частью целочисленного литерала.

Например:

```nexel
-42
```

с точки зрения лексического анализа состоит из оператора `-` и целочисленного литерала `42`.

Проверка допустимого диапазона значения типа `int` не относится к задаче лексического анализатора.

### 2.7. Строковые литералы

Строковые литералы заключаются в двойные кавычки:

```nexel
"Hello"
```

Пустая строка также является корректной:

```nexel
""
```

Примеры:

```nexel
"Hello, world!"
"Nexel"
"123"
"Hello world"
```

В строках поддерживаются следующие escape-последовательности:

| Последовательность | Значение |
| --- | --- |
| `\"` | двойная кавычка |
| `\\` | обратная косая черта |
| `\n` | перевод строки |
| `\r` | возврат каретки |
| `\t` | горизонтальная табуляция |

Примеры:

```nexel
"Hello\nWorld"
"Column1\tColumn2"
"\"Nexel\""
"C:\\Temp\\file.txt"
```

Неэкранированный перевод строки внутри строкового литерала не допускается.

Незакрытый строковый литерал является лексической ошибкой.

Неизвестная escape-последовательность также является лексической ошибкой.

Например:

```nexel
"\q"
```

является некорректной строкой.

### 2.8. Логические литералы

Nexel содержит два логических литерала:

```text
true
false
```

Они являются зарезервированными ключевыми словами.

Регистр имеет значение: `true` является логическим литералом, а `True` может быть идентификатором.

### 2.9. Операторы

Nexel содержит арифметические и логические операторы, операторы сравнения и оператор присваивания.

Арифметические операторы:

```text
+
-
*
/
%
```

Оператор присваивания:

```text
=
```

Операторы сравнения:

```text
==
!=
<
<=
>
>=
```

Логические операторы:

```text
&&
||
!
```

Составные операторы распознаются как единые лексемы.

Например:

```text
==
<=
>=
!=
&&
||
```

являются отдельными лексемами.

Если из текущей позиции можно распознать несколько вариантов, выбирается наиболее длинная допустимая лексема.

Например, `>=` распознаётся как один оператор, а не как последовательность `>` и `=`.

Одиночные символы `&` и `|` не являются допустимыми операторами Nexel.

Сокращённые операторы присваивания и операторы инкремента и декремента в текущей версии языка не поддерживаются:

```text
+=
-=
*=
/=
++
--
```

### 2.10. Разделители

Nexel использует следующие разделители:

```text
(
)
{
}
[
]
;
,
.
```

Их назначение:

| Разделитель | Назначение |
| --- | --- |
| `(` `)` | группировка выражений, параметры и аргументы функций |
| `{` `}` | границы блока |
| `[` `]` | работа с массивами |
| `;` | завершение инструкции |
| `,` | разделение элементов |
| `.` | обращение к полям структуры |

Каждый разделитель является отдельной лексемой.

### 2.11. Выбор лексемы

Лексический анализ выполняется слева направо.

Если из текущей позиции можно распознать несколько лексем, выбирается наиболее длинная подходящая последовательность символов.

Например:

```text
>=
```

распознаётся как один оператор `>=`.

Ключевое слово распознаётся только при полном совпадении.

Например:

```text
while
```

является ключевым словом, а:

```text
whileCount
```

является одним идентификатором.

### 2.12. Лексические ошибки

Лексической ошибкой является последовательность символов, которая не соответствует ни одной допустимой лексеме Nexel.

К лексическим ошибкам относятся:

- неизвестный символ;
- незавершённый строковый литерал;
- неизвестная escape-последовательность;
- незавершённый многострочный комментарий;
- одиночный символ `&`;
- одиночный символ `|`.

При обнаружении лексической ошибки анализатор должен сообщить о ней с указанием позиции в исходном тексте.
