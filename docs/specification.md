# Спецификация языка Nexel

## 1. Введение

Nexel — учебный императивный язык программирования с синтаксисом, близким к C. Программа располагается в одном исходном файле, точкой входа является функция `void main()`.

В четвёртой итерации поддерживаются числовые типы `int` и `double`, логический тип `bool`, управляющие конструкции (`if`/`else`, `while`, `for`), составные присваивания (`+=`, `-=`, `*=`, `/=`), функции с параметрами и возвращаемыми значениями, явные преобразования числовых типов и встроенные функции ввода-вывода и математики. Инструкции завершаются точкой с запятой.

Лексический анализатор также распознаёт конструкции, зарезервированные для будущих итераций.

## 2. Лексика

### 2.1. Пробельные символы

Вне строковых литералов игнорируются:

| Символ | Обозначение |
| --- | --- |
| пробел | ` ` |
| горизонтальная табуляция | `\t` |
| перевод строки | `\n` |
| возврат каретки | `\r` |

### 2.2. Комментарии

Поддерживаются два вида комментариев:

- `//` — однострочный комментарий;
- `/* ... */` — многострочный комментарий.

Вложенные многострочные комментарии не поддерживаются.

### 2.3. Идентификаторы

Идентификатор состоит из латинских букв, цифр и символа `_`. Первый символ должен быть латинской буквой или `_`.

```text
identifier ::= (letter | "_") (letter | digit | "_")*
letter     ::= "a".."z" | "A".."Z"
digit      ::= "0".."9"
```

Кириллица в идентификаторах не допускается.

### 2.4. Ключевые слова

Зарезервированные слова:

```text
int double string bool void
if else while for return struct
true false
```

Имена `main`, `print`, `readInt`, `printDouble`, `readDouble`, `toDouble`, `toInt`, `abs`, `min` и `max` распознаются как идентификаторы и зарезервированы как имена встроенных функций или точки входа.

### 2.5. Числовые литералы

Целочисленный литерал — непустая последовательность десятичных цифр:

```text
integer_literal ::= digit+
```

Допустимый диапазон значений `int`: от 0 до 2147483647. Знак `-` обрабатывается как отдельный унарный оператор.

Вещественный литерал состоит из десятичных цифр до и после точки:

```text
double_literal ::= digit+ "." digit+
```

Записи вида `1.` или `.5` не являются вещественными литералами; одиночный символ `.` распознаётся как отдельный разделитель. Знаки `+` и `-` обрабатываются как отдельные унарные операторы. Экспоненциальный синтаксис в литералах не поддерживается; неконечные литералы запрещены.

### 2.6. Строковые литералы

Строковый литерал заключается в двойные кавычки:

```text
string_literal ::= '"' (string_char | escape)* '"'
```

Здесь `string_char` — символ, кроме неэкранированных кавычки, обратной косой черты и перевода строки; `escape` — одна из последовательностей:

| Последовательность | Назначение |
| --- | --- |
| `\"` | двойная кавычка |
| `\\` | обратная косая черта |
| `\n` | перевод строки |
| `\r` | возврат каретки |
| `\t` | горизонтальная табуляция |

### 2.7. Логические литералы

`true` и `false` являются ключевыми словами.

### 2.8. Операторы

| Категория | Операторы |
| --- | --- |
| арифметические | `+` `-` `*` `/` `%` |
| присваивание | `=` `+=` `-=` `*=` `/=` |
| сравнение | `==` `!=` `<` `<=` `>` `>=` |
| логические | `&&` `\|\|` `!` |

Одиночные `&` и `|` недопустимы.

### 2.9. Разделители

| Лексема | Назначение |
| --- | --- |
| `(` `)` | круглые скобки |
| `{` `}` | фигурные скобки |
| `[` `]` | квадратные скобки |
| `;` | конец инструкции |
| `,` | разделитель элементов |
| `.` | разделитель доступа к полям |

## 3. Синтаксис

Программа состоит из объявлений глобальных переменных и определений функций. Точка входа — единственная функция `void main()` без параметров. Функции содержат блоки инструкций; блоки могут быть вложенными.

Поддерживаются типы значений `int`, `bool` и `double`, а также возвращаемый тип `void` для функций. Объявление переменной обязательно содержит инициализатор. Присваивание и составное присваивание являются отдельными инструкциями, а не выражениями.

### 3.1. EBNF-грамматика

```ebnf
program = { external_declaration } ;

external_declaration = global_variable_declaration
                     | function_definition ;

global_variable_declaration = value_type, identifier, "=", global_initializer, ";" ;

global_initializer = global_logical_or_expression ;
global_logical_or_expression = global_logical_and_expression,
    { "||", global_logical_and_expression } ;
global_logical_and_expression = global_equality_expression,
    { "&&", global_equality_expression } ;
global_equality_expression = global_relational_expression,
    { ("==" | "!="), global_relational_expression } ;
global_relational_expression = global_additive_expression,
    { ("<" | "<=" | ">" | ">="), global_additive_expression } ;
global_additive_expression = global_multiplicative_expression,
    { ("+" | "-"), global_multiplicative_expression } ;
global_multiplicative_expression = global_unary_expression,
    { ("*" | "/" | "%"), global_unary_expression } ;
global_unary_expression = { "+" | "-" | "!" }, global_primary_expression ;
global_primary_expression = integer_literal
                           | double_literal
                           | "true"
                           | "false"
                           | "(", global_initializer, ")" ;

function_definition = function_return_type, identifier,
    "(", [ parameter_list ], ")", block ;
function_return_type = value_type | "void" ;
value_type = "int" | "bool" | "double" ;
parameter_list = parameter, { ",", parameter } ;
parameter = value_type, identifier ;

block = "{", { statement }, "}" ;

statement = local_variable_declaration
          | assignment_statement
          | return_statement
          | if_statement
          | while_statement
          | for_statement
          | block
          | expression_statement ;

local_variable_declaration = value_type, identifier, "=", expression, ";" ;
assignment = identifier, assignment_operator, expression ;
assignment_operator = "=" | "+=" | "-=" | "*=" | "/=" ;
assignment_statement = assignment, ";" ;
return_statement = "return", [ expression ], ";" ;
if_statement = "if", "(", expression, ")", block, [ "else", block ] ;
while_statement = "while", "(", expression, ")", block ;
for_statement = "for", "(", ( local_variable_declaration_no_semi | assignment ), ";",
    expression, ";", assignment, ")", block ;
local_variable_declaration_no_semi = value_type, identifier, "=", expression ;
expression_statement = expression, ";" ;

expression = logical_or_expression ;
logical_or_expression = logical_and_expression,
    { "||", logical_and_expression } ;
logical_and_expression = equality_expression,
    { "&&", equality_expression } ;
equality_expression = relational_expression,
    { ("==" | "!="), relational_expression } ;
relational_expression = additive_expression,
    { ("<" | "<=" | ">" | ">="), additive_expression } ;
additive_expression = multiplicative_expression,
    { ("+" | "-"), multiplicative_expression } ;
multiplicative_expression = unary_expression,
    { ("*" | "/" | "%"), unary_expression } ;
unary_expression = { "+" | "-" | "!" }, primary_expression ;
primary_expression = integer_literal
                   | double_literal
                   | "true"
                   | "false"
                   | "(", expression, ")"
                   | identifier, [ call_suffix ] ;

call = identifier, call_suffix ;
call_suffix = "(", [ argument_list ], ")" ;
argument_list = expression, { ",", expression } ;
```

В `primary_expression` общая форма `identifier, [ call_suffix ]` означает чтение переменной, если хвоста вызова нет, и вызов функции, если присутствует `(...)`. Правило `call` именует второй вариант этой формы.

У `external_declaration` общая начальная часть `value_type identifier`. После неё `(` означает определение функции, а `=` — объявление глобальной переменной. Это различие следует обрабатывать факторизованным разбором.

Глобальный инициализатор намеренно использует отдельную группу правил: в нём разрешены только литералы, скобки и операции над ними. Имена переменных и вызовы функций в нём грамматически недопустимы.

### 3.2. Приоритеты операторов

| Приоритет | Операторы | Ассоциативность |
| --- | --- | --- |
| 1 (высший) | унарные `+`, `-`, `!` | справа налево |
| 2 | `*`, `/`, `%` | слева направо |
| 3 | `+`, `-` | слева направо |
| 4 | `<`, `<=`, `>`, `>=` | слева направо |
| 5 | `==`, `!=` | слева направо |
| 6 | `&&` | слева направо |
| 7 (низший) | `\|\|` | слева направо |

Оператор `%` вычисляет остаток от целочисленного деления и разрешён только для `int`.

`readInt()` считывает целое число из стандартного ввода (`InvariantCulture`).

`print(expression)` выводит значение выражения типа `int` с переводом строки (`InvariantCulture`).

`readDouble()` считывает конечное значение `double` из стандартного ввода (`NumberStyles.Float`, `InvariantCulture`, без разделителей тысяч); неконечные значения (`NaN`, `Infinity`) вызывают ошибку выполнения.

`printDouble(expression)` выводит значение выражения типа `double` с переводом строки в round-trip формате `"R"` (`InvariantCulture`).

`toDouble(expression)` преобразует значение типа `int` в `double` без потери точности.

`toInt(expression)` усекает конечное значение типа `double` к нулю; при `NaN`, `Infinity` или выходе усечённого значения за пределы `int` возникает ошибка выполнения.

Результат выражения-инструкции отбрасывается; после вызова `void` удалять значение со стека не требуется.

### 3.3. Переменные и области видимости

Переменные и параметры имеют типы `int`, `bool` или `double`. Неявные преобразования между типами запрещены; преобразования между `bool` и числовыми типами не поддерживаются. Операнды арифметических операций и сравнений должны иметь один и тот же числовой тип (`int` и `int` либо `double` и `double`). Инициализация обязательна как для глобальных, так и для локальных переменных:

```c
double globalValue = 10.5;

void main() {
    double localValue = globalValue + 2.5;
    localValue *= 2.0;
    printDouble(localValue);
}
```

Глобальные переменные объявляются на верхнем уровне программы. Они доступны из тел функций. Все глобальные инициализаторы вычисляются до вызова `main` в порядке объявлений. Поскольку глобальный инициализатор может содержать только литералы, скобки и операции над ними, он не может читать другую переменную, вызывать функцию или выполнять ввод-вывод.

Локальная переменная видна начиная с места объявления и до конца блока, в котором объявлена. При разборе и проверке инициализатора имя новой переменной ещё не добавлено в текущее окружение. Поэтому `int x = x + 1;` допустимо только тогда, когда до объявления доступна другая переменная `x` во внешней области.

В пределах одного блока повторное объявление имени запрещено. Вложенный блок образует новую область видимости и может объявить переменную с именем внешней переменной. Такое затенение не изменяет значение внешней переменной:

```c
void main() {
    int value = 1;
    {
        int value = 2;
        print(value); // 2
    }
    print(value); // 1
}
```

Параметры функции и её внешний блок тела образуют одну область видимости. Поэтому параметр нельзя повторно объявить локальной переменной непосредственно во внешнем блоке функции. Во вложенном блоке затенение параметра разрешено. Заголовок цикла `for` образует собственную область видимости для переменной, объявленной в инициализаторе цикла.

Области видимости лексические, а не динамические: функция видит глобальные переменные и собственные локальные переменные/параметры, но не получает доступ к локальным переменным функции, которая её вызвала.

Имена глобальных переменных не могут совпадать с именами функций. Имена `main`, пользовательских функций и встроенных функций нельзя использовать для локальных переменных и параметров. Повторные объявления переменных в одной области видимости запрещены.

Присваивание записывается отдельной инструкцией `identifier = expression;`. Составные присваивания `+=`, `-=`, `*=` и `/=` поддерживаются только для числовых переменных (`int` и `double`) при точном совпадении типа переменной и правой части; при `x op= expr` значение `x` считывается до вычисления `expr`, а правая часть вычисляется один раз. Цепочки присваиваний (`a = b = 1`) и присваивания внутри выражений не поддерживаются.

### 3.4. Функции и вычисления

Функции объявляются только на верхнем уровне. Поддерживаются функции с возвращаемыми типами `int`, `bool`, `double` и `void`:

- `int`, `bool`, `double` — функция обязана вернуть значение соответствующего типа;
- `void` — функция не возвращает значение.

Параметры могут иметь типы `int`, `bool` или `double`. Функции могут иметь любое количество параметров, в том числе ноль. Перегрузка и вложенные определения функций не поддерживаются.

В программе должна быть ровно одна точка входа `void main()` без параметров. Явный вызов `main()` из исходной программы запрещён. Пользовательскую функцию можно вызвать до её определения: при проверке программы сначала собираются сигнатуры всех функций, затем проверяются их тела.

Аргументы вызова вычисляются слева направо. Параметры получают значения по значению: изменение параметра внутри функции не изменяет переменную вызывающего кода. Операнды арифметических выражений также вычисляются слева направо.

Правила возврата:

- `return expression;` используется в функциях с возвращаемым значением; тип выражения должен совпадать с возвращаемым типом функции.
- `return;` используется в функции `void`.
- Функция `void`, достигшая конца тела, завершается неявным возвратом.
- Функция с возвращаемым значением должна гарантированно вернуть значение.
- `return` внутри вложенного блока завершает всю текущую функцию, а не только блок.

Вызов функции `void` разрешён только как самостоятельная инструкция. Его нельзя использовать как значение в арифметике, аргументе другой функции, инициализаторе переменной или `return expression`. Результат выражения-инструкции типа `int` или `double` отбрасывается; после вызова `void` удалять значение со стека не требуется.

Синтаксические и семантические ошибки должны обнаруживаться до запуска виртуальной машины. Если в программе есть ошибка компиляции, никакие инструкции программы не выполняются: в частности, предшествующий ошибке `print` не должен успеть вывести данные.

### 3.5. Встроенные функции и ограничения

Встроенные функции доступны без отдельного объявления. Для каждой функции требуется точное число аргументов:

| Функция | Аргументы | Результат | Поведение |
| --- | --- | --- | --- |
| `readInt()` | 0 | `int` | Считывает одну строку стандартного ввода и разбирает знаковое десятичное 32-битное целое число (`InvariantCulture`). |
| `print(value)` | 1 (`int`) | `void` | Выводит целое число с переводом строки (`InvariantCulture`). |
| `readDouble()` | 0 | `double` | Считывает строку и разбирает конечное число `double` (`NumberStyles.Float`, `InvariantCulture`, без разделителей тысяч). Неконечные значения вызывают ошибку выполнения. |
| `printDouble(value)` | 1 (`double`) | `void` | Выводит значение `double` с переводом строки в round-trip формате `"R"` (`InvariantCulture`). |
| `toDouble(value)` | 1 (`int`) | `double` | Преобразует `int` в `double` без потери точности. |
| `toInt(value)` | 1 (`double`) | `int` | Усекает конечное значение `double` к нулю; при `NaN`, `Infinity` или выходе усечённого значения за пределы `int` возникает ошибка выполнения. |
| `abs(value)` | 1 (`int`) | `int` | Возвращает модуль целого числа. Для минимального `int` возникает ошибка переполнения. |
| `min(left, right)` | 2 (`int`) | `int` | Возвращает меньшее из двух целых чисел. |
| `max(left, right)` | 2 (`int`) | `int` | Возвращает большее из двух целых чисел. |

`readInt`, `print`, `readDouble`, `printDouble`, `toDouble`, `toInt`, `abs`, `min` и `max` являются именами встроенных функций. Их нельзя повторно объявлять как пользовательские функции или использовать в качестве имён локальных переменных и параметров. Встроенные функции не поддерживают произвольное число аргументов.

Целочисленные литералы сохраняют диапазон: от `0` до `2147483647`. Знак `-` является отдельным унарным оператором. Поэтому литерал `-2147483648` напрямую не записывается; минимальное значение `int` можно получить вводом или выражением `-2147483647 - 1`. Переполнение целой арифметики и деление на ноль для `int` являются ошибками выполнения; для `double` применяются правила IEEE 754 (`NaN`, `Infinity`).
