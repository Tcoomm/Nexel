# Nexel

Nexel — учебный язык программирования, разрабатываемый в рамках курса по интерпретаторам и компиляторам.

Проект реализуется на C# 14 и .NET 10.

## Структура проекта

- `tests` — автоматические тесты
- `scripts` — вспомогательные скрипты
