# Nexel

Nexel — учебный язык программирования, разрабатываемый в рамках курса по интерпретаторам и компиляторам.

Проект реализуется на C# 14 и .NET 10.

## Структура проекта

* `src` — исходный код проекта
* `tests` — автоматические тесты
* `docs` — спецификация языка
* `scripts` — вспомогательные скрипты

## Сборка

```bash
dotnet build
```

## Тесты

```bash
dotnet test
```
## Запуск интерпретатора

Интерпретатор выполняет программы Nexel из файлов с расширением `.nex`.

Например:

```c
void main() {
    print(10 + 2 * 5);
    print(readInt() + 1);
}

Запуск:

```powershell
dotnet run --project src/Nexel.Cli -- example.nex
```

Программа использует стандартный ввод и вывод. При ошибке сообщение выводится в stderr, а процесс завершается с ненулевым кодом.
